Restore & Snapshots

Recover safely using a separate database.

For a hosted PostgreSQL database, restoration is managed in Render → Database → Recovery. You can inspect available recovery times there, and recover into a new database without overwriting production immediately.

One-click live restore is intentionally disabled here. Restoring directly inside a running web request could interrupt purchases, sensor writes, logins, and other data updates.
  1. Open the Recovery page for your EnviroPlus PostgreSQL database in Render.
  2. Select a recovery point or export a logical backup, depending on your database plan.
  3. Restore to a separate database and verify orders, users, hardware inventory, and sensor readings.
  4. Switch DATABASE_URL only after the recovered data passes validation and the application is ready for a controlled cutover.
Open Render Dashboard Recovery Guide

A database backup does not automatically include uploaded media files or your server's environment variables. Back those up separately. Render's recovery capabilities depend on your database plan and must not be assumed available on free instances.
